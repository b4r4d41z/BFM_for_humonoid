BFM_for_humonoid/

│   │   └── losses.py           # FB TD-loss, actor loss и др.
│   │
│   ├── utils/                  # вспомогательные утилиты
│   │   ├── __init__.py
│   │   ├── config.py           # работа с конфигами
│   │   ├── logger.py           # логирование

│   │
│   └── vlm/                    # визуально-языковой модуль
│       ├── __init__.py

│
├── main.py                     # точка входа (сборка и запуск обучения)
│
└── README.md                   # описание проекта
